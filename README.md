# Aj Aircon Care Connect

Build a premium, modern and conversion-focused website UI for **AJ AIRCONDITIONING SERVICES**, a Malaysian air-conditioning service business.

## Design direction
- Premium industrial aesthetic using charcoal black, AJ yellow and white.
- Strong typography, generous spacing, clean visual hierarchy and polished responsive layouts.
- Smooth, tasteful animations and hover interactions. Avoid excessive gradients, glassmorphism, glowing effects and generic AI-generated layouts.
- Use the provided AJ logo as the main brand identity. Inspect the uploaded logo and preserve its proportions and appearance.
- Mobile-first design, optimised for Malaysian customers browsing on phones.

## Page sections
1. Responsive navigation with logo and WhatsApp CTA.
2. Hero section with compelling service headline, supporting copy and clear WhatsApp booking button.
3. Air-conditioning services: chemical cleaning, gas top-up and repair.
4. Service pricing: Wall Mounted RM130, Ceiling Cassette RM230, Ceiling Exposed RM230. Prices are not based on horsepower.
5. Supported air-conditioner types.
6. Work gallery with clearly identified temporary placeholders until genuine AJ work photos are provided.
7. Service process, FAQs and contact section.
8. Footer with contact details and service information.

## Technical requirements
- Use a maintainable React-based project structure with TypeScript and Tailwind CSS if supported by the existing project setup.
- Use reusable components and accessible semantic HTML.
- Add subtle scroll-reveal and hover animations with good performance and reduced-motion support.
- Ensure all buttons and navigation links work.
- Use temporary visual assets only where necessary. Never represent stock or generated photos as actual AJ projects.
- Keep image assets easy to replace later, using descriptive filenames and reusable image components.
- Do not invent testimonials, certifications, company history, guarantees or service-area claims.
- Do not publish the RM110 PPR Pudu Ulu promotion as currently active until its validity is confirmed.

First build a cohesive, polished UI with the supplied logo. Focus on visual quality, responsive layouts and a professional customer experience. Keep the code organised for further development in VS Code using Claude Code.
